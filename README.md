CheatNotify
=============

A King Of The Bridge mod to notify when someone just cheated

Installation
------------

1. Get MelonLoader.Installer.exe: https://github.com/LavaGang/MelonLoader.Installer/releases/latest/download/MelonLoader.Installer.exe
2. Use it to install MelonLoader on King of the Bridge (tested MelonLoader v0.7.3)
3. Extract CheatNotify.zip to your King of the Bridge installation folder. It'll put the file CheatNotify.dll into Mods/
4. Run the game
